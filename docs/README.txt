The public Andrea Burkhart archive exposes downloadable court PDFs through Substack download controls. In this build environment those hosted PDF binaries could not be fetched directly, so the website preserves verified live links to the archive rather than pretending local copies were obtained.

Before publishing, you can add any original/redacted PDFs to this docs/ folder and update the matching href values in index.html. The companion site is otherwise self-contained.
